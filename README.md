# RaceAnalyst Web Application

AI-Powered Indian Horse Racing Analysis Platform

## Structure
- /frontend - HTML/CSS/JS dashboard
- /backend - Python FastAPI backend

## Quick Start
### Backend
cd backend
pip install -r requirements.txt
python -m app.main



### Frontend
Open frontend/dashboard.html in browser

## Deployment
- Frontend: Cloudflare Pages
- Backend: Cloudflare Workers / VPS

## Features
- Live race analysis dashboard
- Expert reports (ratings, pedigree, trackwork, etc.)
- Race day reports (track condition, odds, etc.)
- AI-powered insights
